# Explain the number

## Class

Design guidance.

## Applies when

Measuring or using a result for a decision.

## Rule

Set a decision-relevant threshold before measuring; record run count, spread, and the observed limiter. Exclude errors, cached or skipped work, unequal conditions including tuning, noise, and end-to-end irrelevance. An unstable or inconclusive result supports no win.

## Limits

A lone run cannot establish a stable improvement. This does not add a mandatory statistics framework or relax existing deterministic checks.
